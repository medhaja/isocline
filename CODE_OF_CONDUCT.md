# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, focus on the work, and accept that maintainers may remove comments, commits
or contributors that are harassing, discriminatory or otherwise harmful.

**Reporting.** Report unacceptable behaviour privately to the maintainers through GitHub (a private security advisory
works for sensitive reports, or contact a maintainer listed in the repository). Reports are handled confidentially.
Enforcement follows the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).
