Local web search in Isocline Desktop
====================================

IsoclineSearch.exe is a separate program that provides the Web Search tool when no Tavily or Brave key is
configured. It is built from:

    packaging/desktop/build.ps1 as SEARXNG_REF).

You may obtain, modify and redistribute the complete corresponding source of IsoclineSearch.exe under the terms
of the AGPL from the locations above. Isocline itself (Isocline.exe) is licensed under the Apache License 2.0 and
communicates with IsoclineSearch.exe only over HTTP on this computer.
